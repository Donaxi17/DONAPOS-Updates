# DONAPOS - Descargas y actualizaciones

Repositorio oficial de instaladores publicados de DONAPOS para Windows x64.

## Descargar

Abre [Releases](https://github.com/Donaxi17/DONAPOS-Updates/releases/latest) y descarga el instalador de la versión más reciente.

## Actualizaciones automáticas

La aplicación de escritorio consulta las publicaciones de este repositorio. Para publicar una versión nueva, crea una release con el instalador NSIS, su archivo `.blockmap` y `latest.yml`.

La aplicación web no se actualiza automáticamente; descarga e instala la versión de Windows desde Releases.
